1.	**Branching:** Create your feature branch off of `main` (unless you strictly need unreleased code from `dev`).
2.	**Pull Requests:** Submit all PRs to the `dev` branch.
3.	**Software Review:** A maintainer will review and merge your PR into `dev`.
4.	**Hardware Review:** The lab team will test `dev` on the physical hardware and merge it into `main` if successful.
